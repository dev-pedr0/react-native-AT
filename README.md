# App de Receitas
Este projeto foi desenvolvido durante a disciplina de React Native no Instituto Infnet, com o objetivo de aprofundar conhecimentos em desenvolvimento mobile e consumo de APIs externas.
A aplicação é um app de receitas que consome dados da API pública TheMealDB, permitindo explorar pratos, pesquisar receitas e visualizar detalhes completos de preparo.
O projeto também teve foco em responsividade e organização de código utilizando boas práticas com TypeScript.

## Funcionalidades
🎲 Receita Aleatória
- Exibição de uma receita em destaque na tela inicial
- Atualização dinâmica via API
🔎 Busca de Receitas
- Pesquisa por nome do prato
- Consulta dinâmica à API
🗂️ Filtro por Categorias
- Listagem de categorias disponíveis
- Exibição de receitas filtradas
📖 Detalhes da Receita
- Nome do prato
- Imagem
- Lista de ingredientes

## Como Executar
1. A página principal é o index.tsx, fica dentro da pasta app/(tabs)/
2. Clone o programa e, caso precise, uso o comando 'npm install' para instalar as dependencias
3. Use o comando 'npx expo start' para iniciar o programa
